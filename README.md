# Smart-Bin-Using-Arduino UNO
Low-cost automatic dustbin that can detect a nearby object and open its lid without physical contact made by using Arduino UNO,ultrasonic sensor and servo motor

Maintaining cleanliness and proper waste disposal is important for a healthy environment. Conventional dustbins require users to manually touch or open the lid, which can lead to the spread of germs and create inconvenience.
The Smart Dustbin provides an automatic solution by using an ultrasonic sensor and a servo motor. The ultrasonic sensor detects an object placed near the dustbin without requiring physical contact. The Arduino UNO acts as the main control unit and processes the distance information received from the sensor. Based on the detected distance, the Arduino controls the servo motor to open and close the lid automatically.
The project demonstrates how simple electronic components and programming can be combined to create an automated and user-friendly system.
